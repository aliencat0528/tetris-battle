# Tetris - 俄羅斯方塊

一個現代化的俄羅斯方塊遊戲，具有關卡系統、道具、障礙物等進階功能，使用純 HTML5 + CSS3 + JavaScript 實現。

## 遊戲特色

### 關卡系統

| 關卡 | 過關條件 | 特色 | 速度 |
|------|----------|------|------|
| 1 | 消除 2 行 | 有利道具開始出現 | 1000ms |
| 2 | 消除 3 行 | 道具機率提升 | 900ms |
| 3 | 消除 4 行 | 石頭障礙物出現 | 800ms |
| 4 | 消除 4 行 | 時間限制 8 秒/塊 | 700ms |
| 5 | 消除 5 行 | 出局道具出現 | 600ms |
| 6 | 消除 5 行 | 所有機制同時啟用 | 500ms |

### 道具系統

#### 有利道具（關卡 1 起）
獲得方式：放置發光的綠色道具方塊後自動存入道具欄

| 道具 | 圖示 | 效果 | 時效 |
|------|------|------|------|
| 炸彈 | 💣 | 清除當前方塊周圍 3×3 範圍 | 45 秒 |
| 消行器 | ⚡ | 立即消除最底下 1 行 | 45 秒 |
| 時間凍結 | ❄️ | 暫停方塊下落 5 秒 | 60 秒 |
| 變形器 | 🔄 | 將當前方塊變成 I 型 | 60 秒 |
| 破壞鎚 | 🔨 | 清除場上所有障礙物 | 60 秒 |

#### 出局道具（關卡 5 起）
碰到紅色發光的方塊時立即觸發負面效果

| 道具 | 圖示 | 效果 |
|------|------|------|
| 加速 | ⬇️ | 下落速度加倍 10 秒 |
| 迷霧 | 🌫️ | 遮擋上半部視野 8 秒 |
| 反轉 | ↔️ | 左右控制反轉 8 秒 |

### 障礙物系統（關卡 3 起）
- 石頭障礙物隨機出現在遊戲板下半部
- 障礙物**可被消行一起清除**（當整行填滿時）
- 使用「破壞鎚」道具可一次清除所有障礙物

### 時間限制（關卡 4 起）
- 每個方塊有 **8 秒** 放置時間
- 畫面顯示倒數計時器
- 時間到方塊自動消失，生成下一個

### 核心機制
- **Ghost Piece** - 半透明預覽方塊落點位置
- **Hold 系統** - 存入/取出方塊（詳見下方說明）
- **3-Piece Next 預覽** - 顯示接下來 3 個方塊
- **Wall Kick** - SRS 旋轉系統，碰壁自動位移調整
- **Lock Delay** - 觸底後 500ms 延遲，可移動/旋轉重置（最多 15 次）
- **7-Bag 隨機系統** - 確保方塊分布公平

### 計分系統

| 消除行數 | 基本分數 |
|---------|---------|
| 1 行 (Single) | 100 × 關卡數 |
| 2 行 (Double) | 300 × 關卡數 |
| 3 行 (Triple) | 500 × 關卡數 |
| 4 行 (Tetris) | 800 × 關卡數 |

- 連擊 (Combo)：額外 50 × 連擊數 × 關卡數

## 操作說明

### 鍵盤控制

| 按鍵 | 功能 |
|-----|------|
| ← / A | 左移 |
| → / D | 右移 |
| ↓ / S | Soft Drop（快速下降） |
| ↑ / W / X | 順時針旋轉 |
| Z | 逆時針旋轉 |
| 空白鍵 | Hard Drop（瞬間落下） |
| **C / Shift** | **Hold（存入/取出方塊）** |
| **1 / 2 / 3** | **使用道具欄對應道具** |
| P / Esc | 暫停/繼續 |
| R | 重新開始 |
| Enter | 開始遊戲 |

### Hold 方塊操作

| 情境 | 按 C 後的動作 |
|------|--------------|
| Hold 區**空的** | 當前方塊存入 Hold 區 → 自動生成下一個方塊 |
| Hold 區**有方塊** | 取出 Hold 的方塊使用 → 當前方塊丟棄 → Hold 清空 |

**限制**：每個方塊落地前只能按一次 C

**操作範例**：
```
1. 拿到 T 方塊，按 C → T 存入 Hold，生成新方塊
2. 之後拿到 Z 方塊，想用之前存的 T
3. 按 C → Z 被丟棄，T 取出使用，Hold 清空
4. T 落地後，Hold 區已空，可重新存入新方塊
```

### 道具使用

道具欄位於畫面左側，最多可儲存 3 個道具：
```
[1] 💣  ← 按數字鍵 1 使用
[2] ⚡  ← 按數字鍵 2 使用
[3] ❄️  ← 按數字鍵 3 使用
```

- 道具在放置綠色發光方塊後自動獲得
- 使用後該欄位清空
- **道具有時效限制**：普通道具 45 秒，稀有道具 60 秒
- 道具即將過期時會閃爍提示
- 道具欄滿時，可選擇是否替換現有道具
- **出局（Game Over）後所有道具清空**

### 模組說明

| 模組 | 功能 |
|-----|------|
| **Game** | 遊戲主控制器，管理遊戲狀態、迴圈、方塊生成 |
| **Board** | 棋盤邏輯，碰撞檢測、消行、障礙物、Ghost 位置計算 |
| **Piece** | 方塊類別，形狀、旋轉、Wall Kick 資料 |
| **PieceBag** | 7-bag 隨機生成器 |
| **Renderer** | Canvas 渲染，繪製棋盤、方塊、UI、特效 |
| **InputHandler** | 鍵盤輸入處理，按鍵重複 |
| **ScoreManager** | 計分、LocalStorage 高分榜 |
| **StageManager** | 關卡系統管理 |
| **ItemManager** | 道具系統管理 |
