# Tetris Battle - 俄羅斯方塊對戰

一個現代化的俄羅斯方塊遊戲，支援**單人闯關**與**雙人對戰**模式，具有關卡系統、道具、障礙物等進階功能，使用純 HTML5 + CSS3 + JavaScript 實現。

![Version](https://img.shields.io/badge/version-4.3.3-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 遊戲模式

### 🎮 單人模式
經典俄羅斯方塊，挑戰 6 個關卡，難度逐漸提升。

### ⚔️ 雙人對戰模式
兩位玩家在同一台電腦上對戰，消行可發送垃圾行給對手！

## 雙人對戰模式

### 對戰規則
- **時間限制**：3 分鐘
- **勝負判定**：
  1. KO 數較多者獲勝（將對手堆滿出局）
  2. KO 數相同時，送出行數較多者獲勝

### 垃圾行機制
| 消除行數 | 送出垃圾行 |
|---------|-----------|
| 1 行 (Single) | 0 行 |
| 2 行 (Double) | 1 行 |
| 3 行 (Triple) | 2 行 |
| 4 行 (Tetris) | 4 行 |
| 連擊加成 | +連擊數-1 行 |

### 對戰操作

| 功能 | 玩家 1 (左手) | 玩家 2 (右手) |
|------|--------------|--------------|
| 左移 | A | ← |
| 右移 | D | → |
| 軟降 | S | ↓ |
| 硬降 | Space | Enter |
| 順時針旋轉 | W / X | ↑ |
| 逆時針旋轉 | Z | / |
| **Hold** | **C** | **右Shift** 或 **.** |
| **道具 1** | **1** | **7** |
| **道具 2** | **2** | **8** |
| **道具 3** | **3** | **9** |
| 暫停 | P 或 Esc | P 或 Esc |
| 返回選單 | R | R |

### 道具系統（對戰模式）

道具分為**自用道具**和**攻擊道具**：

| 道具 | 圖示 | 效果 | 對象 |
|------|------|------|------|
| 炸彈 | 💣 | 清除周圍 5×5 範圍 | 🟢 自己 |
| 消行器 | ⚡ | 清除最底下 1 行 | 🟢 自己 |
| 變形器 | 🔄 | 隨機變成另一種方塊 | 🟢 自己 |
| 破壞鎚 | 🔨 | 清除所有障礙物 | 🟢 自己 |
| **時間凍結** | **❄️** | **凍結對手方塊下落 5 秒** | **🔴 對手** |

> **提示**：時間凍結是唯一的攻擊道具，會讓對手無法控制方塊下落 5 秒！

## 單人模式

### 關卡系統

| 關卡 | 過關條件 | 特色 | 速度 | 垃圾行 |
|------|----------|------|------|--------|
| 1 | 消除 2 行 | 有利道具開始出現 | 1000ms | 30秒/1行 |
| 2 | 消除 3 行 | 道具機率提升 | 900ms | 28秒/1行 |
| 3 | 消除 4 行 | 石頭障礙物出現 | 800ms | 25秒/1行 |
| 4 | 消除 4 行 | 時間限制 8 秒/塊 | 700ms | 22秒/2行 |
| 5 | 消除 5 行 | 出局道具出現 | 600ms | 20秒/2行 |
| 6 | 消除 5 行 | 所有機制同時啟用 | 500ms | 15秒/3行 |

### 垃圾行機制（單人模式）

單人模式中，垃圾行會定期從底部升起，增加遊戲挑戰性：

- **定時升起**：每隔一段時間自動從底部添加垃圾行
- **難度遞增**：關卡越高，間隔越短、行數越多
- **消除方式**：垃圾行有一格空隙，填滿整行即可消除
- **策略提示**：保持底部整潔，優先消除垃圾行避免堆積

### 道具系統

#### 有利道具（關卡 1 起）
獲得方式：放置發光的綠色道具方塊後自動存入道具欄

| 道具 | 圖示 | 效果 | 時效 |
|------|------|------|------|
| 炸彈 | 💣 | 清除當前方塊周圍 5×5 範圍 | 45 秒 |
| 消行器 | ⚡ | 立即消除最底下 1 行 | 45 秒 |
| 時間凍結 | ❄️ | 暫停方塊下落 5 秒 | 60 秒 |
| 變形器 | 🔄 | 隨機變成另一種方塊 | 60 秒 |
| 破壞鎚 | 🔨 | 清除場上所有障礙物 | 60 秒 |

#### 出局道具（關卡 5 起）
碰到紅色發光的方塊時立即觸發負面效果

| 道具 | 圖示 | 效果 |
|------|------|------|
| 加速 | ⬇️ | 下落速度加倍 10 秒 |
| 迷霧 | 🌫️ | 遮擋上半部視野 8 秒 |
| 反轉 | ↔️ | 按 ← 會向右移，按 → 會向左移 8 秒 |
| 無預覽 | 👻 | 隱藏落點預覽 8 秒 |
| 混亂 | 🌀 | 方塊會自動隨機左右移動 6 秒 |

### 障礙物系統（關卡 3 起）
- 石頭障礙物隨機出現在遊戲板下半部
- 障礙物**可被消行一起清除**（當整行填滿時）
- 使用「破壞鎚」道具可一次清除所有障礙物

### 時間限制（關卡 4 起）
- 每個方塊有 **8 秒** 放置時間
- 畫面顯示倒數計時器
- 時間到方塊自動消失，生成下一個

### 核心機制
- **Ghost Piece** - 半透明預覽方塊落點位置
- **Hold 系統** - 存入/取出方塊（詳見下方說明）
- **3-Piece Next 預覽** - 顯示接下來 3 個方塊
- **Wall Kick** - SRS 旋轉系統，碰壁自動位移調整
- **Lock Delay** - 觸底後 500ms 延遲，可移動/旋轉重置（最多 15 次）
- **7-Bag 隨機系統** - 確保方塊分布公平

### 計分系統

| 消除行數 | 基本分數 |
|---------|---------|
| 1 行 (Single) | 100 × 關卡數 |
| 2 行 (Double) | 300 × 關卡數 |
| 3 行 (Triple) | 500 × 關卡數 |
| 4 行 (Tetris) | 800 × 關卡數 |

- 連擊 (Combo)：額外 50 × 連擊數 × 關卡數

## 操作說明

### 鍵盤控制

| 按鍵 | 功能 |
|-----|------|
| ← / A | 左移 |
| → / D | 右移 |
| ↓ / S | Soft Drop（快速下降） |
| ↑ / W / X | 順時針旋轉 |
| Z | 逆時針旋轉 |
| 空白鍵 | Hard Drop（瞬間落下） |
| **C / Shift** | **Hold（存入/取出方塊）** |
| **1 / 2 / 3** | **使用道具欄對應道具** |
| P / Esc | 暫停/繼續 |
| R | 重新開始 |
| Enter | 開始遊戲 |

### Hold 方塊操作

| 情境 | 按 C 後的動作 |
|------|--------------|
| Hold 區**空的** | 當前方塊存入 Hold 區 → 自動生成下一個方塊 |
| Hold 區**有方塊** | 取出 Hold 的方塊使用 → 當前方塊丟棄 → Hold 清空 |

**限制**：每個方塊落地前只能按一次 C

**操作範例**：
```
1. 拿到 T 方塊，按 C → T 存入 Hold，生成新方塊
2. 之後拿到 Z 方塊，想用之前存的 T
3. 按 C → Z 被丟棄，T 取出使用，Hold 清空
4. T 落地後，Hold 區已空，可重新存入新方塊
```

### 道具使用

道具欄位於畫面左側，最多可儲存 3 個道具：
```
[1] 💣  ← 按數字鍵 1 使用
[2] ⚡  ← 按數字鍵 2 使用
[3] ❄️  ← 按數字鍵 3 使用
```

- 道具在放置綠色發光方塊後自動獲得
- 使用後該欄位清空
- **道具有時效限制**：普通道具 45 秒，稀有道具 60 秒
- 道具即將過期時會閃爍提示
- 道具欄滿時，可選擇是否替換現有道具
- **出局（Game Over）後所有道具清空**

### 模組說明

| 模組 | 功能 |
|-----|------|
| **Game** | 遊戲主控制器，管理遊戲狀態、迴圈、方塊生成 |
| **Board** | 棋盤邏輯，碰撞檢測、消行、障礙物、Ghost 位置計算 |
| **Piece** | 方塊類別，形狀、旋轉、Wall Kick 資料 |
| **PieceBag** | 7-bag 隨機生成器 |
| **Renderer** | Canvas 渲染，繪製棋盤、方塊、UI、特效 |
| **InputHandler** | 鍵盤輸入處理，按鍵重複 |
| **ScoreManager** | 計分、LocalStorage 高分榜 |
| **StageManager** | 關卡系統管理 |
| **ItemManager** | 道具系統管理 |
| **EffectsManager** | 視覺特效管理器，主題切換、背景動畫、遊戲互動動畫 |

## 使用方式

### 方法一：直接開啟（推薦）
```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 方法二：本地伺服器
```bash
# 使用 Python
python3 -m http.server 8100

# 使用 Node.js (需安裝 http-server)
npx http-server -p 8100

# 訪問
open http://localhost:8100
```

### 方法三：DevContainer
1. 在 VS Code 中打開專案
2. 按 F1 → "Dev Containers: Reopen in Container"
3. 執行 `python3 -m http.server 8100`
4. 訪問 `http://localhost:8100`

| 用途 | 端口 |
|-----|------|

本專案使用端口 **8100**，屬於 `claude prototype` 專案段（8100-8199）。

- **渲染**：HTML5 Canvas 2D API

- **儲存**：LocalStorage（高分榜）

## 視覺主題系統

遊戲提供三種獨特的視覺主題，可在右上角即時切換：

### 🫧 夢幻泡泡風（預設）
- **背景特效**：彩虹漸層背景 + 水波紋漣漪 + 夢幻光暈
- **動態元素**：大量漂浮泡泡 (最多35個)，多方向擴散效果（上下左右四方漂浮）
- **配色**：夢幻彩虹系 - 粉紫、淡紫、淡藍、薄荷綠、淡黃、淡橘，底部白色漸變
- **字體**：高彩度漸層（桃紅→紫→藍→青綠→橘黃），與背景形成對比

### 🍬 霓虹糖果風
- **背景特效**：斜向條紋 + 底部粉紫波浪動畫
- **動態元素**：漂浮愛心形狀（CSS 繪製），保留原有粉紫黃漸層與光暈效果
- **配色**：粉色 (#ff96c8)、紫色 (#c896e8)、黃色 (#ffe664) 甜美色系

### 🚀 星際太空風
- **背景特效**：星空點點 + 旋轉星雲漩渦
- **動態元素**：大流星 (200px 帶尾跡) + 兩顆旋轉星球（斜對角位置）
- **配色**：紫色 (#8a2be2) → 藍色 (#4169e1) → 淺藍 (#1e90ff)

### 遊戲互動動畫

| 事件 | 動畫效果 |
|------|----------|
| 遊戲失敗 | 鼓勵訊息 + 柔和彩紙特效 |
| 通關/勝利 | 煙火特效 + 閃爍星星 + 彩紙慶祝 |
| 消行 | 彩虹波紋擴散 + 粒子爆炸 + 方塊碎片飛散 |
| Tetris | 屏幕彩虹濾鏡 + 多重煙火 |
| 連擊 | 根據連擊數增加閃爍星星 |
| 關卡完成 | 煙火 + 彩紙慶祝 |
| 新紀錄 | 彩虹漸層閃爍文字 |

> **提示**：主題選擇會自動保存，下次進入遊戲會自動載入上次選擇的主題。
