## 輸入處理流程

```
┌────────────────┐
│  keydown 事件   │
└───────┬────────┘
        │
        ▼
┌────────────────────────┐
│  InputHandler.handle() │
│  或 BattleInputHandler │
└───────┬────────────────┘
        │
        ▼
┌────────────────────────────┐
│  判斷按鍵屬於哪個玩家       │
│  (單人: 1, 對戰: 1 或 2)   │
└───────┬────────────────────┘
        │
        ├──► 移動鍵 ──► game.move(direction)
        │
        ├──► 旋轉鍵 ──► game.rotate(direction)
        │
        ├──► 下落鍵 ──► game.softDrop() / hardDrop()
        │
        ├──► Hold鍵 ──► game.hold()
        │
        ├──► 道具鍵 ──► game.useItem(slot)
        │
        └──► 系統鍵 ──► pause() / restart()
```

## 道具系統流程

```
┌────────────────────────┐
│  方塊放置時檢測         │
└───────┬────────────────┘
        │
        ▼
┌────────────────────────────┐
│  itemManager.checkSpawn()  │
│  根據機率決定是否生成道具方塊│
└───────┬────────────────────┘
        │
        ├──► 有利道具方塊 (綠色發光)
        │    │
        │    ▼ 放置時
        │    ┌────────────────────┐
        │    │  隨機獲得有利道具   │
        │    │  存入道具欄 (1-3)  │
        │    └────────────────────┘
        │
        └──► 出局道具方塊 (紅色發光)
             │
             ▼ 碰觸時
             ┌────────────────────┐
             │  立即觸發負面效果   │
             │  (加速/迷霧/反轉等) │
             └────────────────────┘

道具使用流程:
┌────────────────┐
│  按 1/2/3 鍵   │
└───────┬────────┘
        │
        ▼
┌────────────────────────┐
│  useItem(slot)         │
│  檢查道具欄是否有道具   │
└───────┬────────────────┘
        │
        ├──► 💣 炸彈 ──► 清除周圍 5×5
        │
        ├──► ⚡ 消行器 ──► 清除最底行
        │
        ├──► ❄️ 凍結 ──► 凍結自己(單人) / 對手(對戰)
        │
        ├──► 🔄 變形器 ──► 隨機變成另一種方塊
        │
        └──► 🔨 破壞鎚 ──► 清除所有障礙物
```

## 模組詳細說明

| 模組 | 檔案 | 職責 |
|-----|------|------|
| **Game** | `index.html` | 遊戲主控制器，管理遊戲狀態、迴圈、方塊生成 |
| **BattleGame** | `index.html` | 對戰模式控制器，管理雙玩家、計時、垃圾行發送 |
| **PlayerGame** | `index.html` | 對戰模式中的單一玩家實例 |
| **Board** | `src/Board.js` | 棋盤邏輯，碰撞檢測、消行、障礙物、Ghost 位置計算 |
| **Piece** | `src/Piece.js` | 方塊類別，形狀、旋轉、Wall Kick 資料 |
| **PieceBag** | `src/Piece.js` | 7-bag 隨機生成器 |
| **Renderer** | `src/Renderer.js` | Canvas 渲染，繪製棋盤、方塊、UI、特效 |
| **InputHandler** | `src/InputHandler.js` | 鍵盤輸入處理，按鍵重複 |
| **ScoreManager** | `src/ScoreManager.js` | 計分、LocalStorage 高分榜 |
| **StageManager** | `index.html` | 關卡系統管理 |
| **ItemManager** | `index.html` | 道具系統管理 |
| **EffectsManager** | `src/effects.js` | 視覺特效管理器，主題切換、背景動畫、遊戲互動動畫 |
